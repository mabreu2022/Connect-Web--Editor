🚀 1. Configurando o Ambiente Local

Como os arquivos do projeto e a compilação final ocorrem no seu computador, é necessário ter a infraestrutura local configurada. Siga os passos:

  1. Instale o Node.js (Versão 18 ou superior) no seu computador.
  2. Baixe os arquivos da pasta Tools/ do nosso repositório para o seu HD.
  3. No seu computador local, abra o prompt de comando (CMD) na pasta Tools/ e instale as dependências executando:
npm install
  1. Configure o arquivo de agente local executando o servidor de sincronização com o comando:
node server-logs.js
⚠️ REQUISITO LAZARUS: Certifique-se de que o Lazarus está instalado em C:\lazarus\ e que o arquivo lazbuild.exe está disponível naquele caminho. Caso contrário, o gerador não conseguirá compilar os sistemas!

🦙 2. Configuração do Ollama (IA Local)

Para rodar o assistente de IA localmente no seu computador e evitar custos com APIs de nuvem:

  1. Faça o download do Ollama através do site oficial: ollama.com e instale-o.
  2. Após iniciar o Ollama no Windows, abra o CMD e baixe o modelo de IA recomendado com o comando:
ollama run qwen2.5-coder:7b

💻 3. Guia de Escolha do Melhor Modelo (RAM vs VRAM)

Escolha o modelo do Ollama ideal baseado na capacidade de hardware (placa de vídeo GPU NVIDIA e memória RAM) do seu computador local:

Hardware Recomendado Modelo Sugerido Comando para Instalar Desempenho no Lazarus
Até 8GB RAM / 4GB GPU (PC Básico) qwen2.5-coder:1.5b ollama pull qwen2.5-coder:1.5b Rápido, mas gera códigos mais simples.
16GB RAM / 6GB-8GB GPU (Recomendado) qwen2.5-coder:7b ollama pull qwen2.5-coder:7b Excelente! Código completo em Pascal e bom tempo de resposta.
32GB RAM / 12GB+ GPU (Alta Performance) qwen2.5-coder:14b ollama pull qwen2.5-coder:14b Extremamente preciso, com excelente estruturação MVC.

🔗 4. Rodando o Gerador

Com o server-logs.js e o Ollama rodando localmente no seu PC:

  • Faça login na plataforma SaaS.
  • Ative sua diária Pix de 24h.
  • Abra a tela do Gerador, informe os caminhos locais (banco de dados Firebird local, pasta de saída) e clique em "Gerar". A mágica acontecerá localmente!
